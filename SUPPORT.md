# Support

Agent Workspace is community-supported, pre-1.0 software.

- Use GitHub Issues for reproducible bugs and focused feature requests.
- Use GitHub Discussions, when enabled, for setup questions and ideas.
- Include your Agent Workspace version, Node.js version, deployment shape, browser, relevant sanitized logs, and reproduction steps.
- Never post API keys, OAuth secrets, shared secrets, cookies, private transcripts, or database files.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
