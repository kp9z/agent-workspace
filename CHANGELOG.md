# Changelog

All notable changes to Agent Workspace are documented here. The project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and uses semantic versioning while allowing pre-1.0 breaking changes.

## [Unreleased]

### Added

- Open-source project documentation and community health files
- Persistent Hermes `/v1/runs` history capability enforcement and continuity regression
- Production authentication modes, request-origin validation, bounded request bodies, image validation, security headers, and rate limiting
- SQLite-aware online backup and guarded atomic restore

### Changed

- Neutral Agent Workspace branding and runtime identifiers with legacy migration aliases
- SQLite persistence, session summaries, and runtime continuity behavior

## [0.1.4] - 2026-07-16

### Added

- Chat-first Next.js PWA with persistent sessions, projects, queueing, attachments, tool progress, approvals, stop, and steering controls
- Stateful mock Hermes runtime and smoke/regression tooling
